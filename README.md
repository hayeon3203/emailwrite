# EmailWrite

Outlook 메신저 창에 떠서 답장 초안을 써주는 아바타 앱입니다. 클래식 데스크톱 Outlook과 연동되며 로컬 LLM으로 완전히 오프라인에서 동작합니다.

## 주요 기능

1. Outlook 클래식 데스크톱(Win32 COM)에서 메일 내용을 읽어 답장 초안을 생성합니다.
2. 기본 모델은 CLOVA 1.5B이며 GGUF 형식으로 로컬에서 실행됩니다. GPU가 있으면 Vulkan으로 레이어를 올려 속도를 높입니다.
3. 첫 실행에서만 약 1.06GB 모델을 내려받고 이후로는 네트워크 없이 완전히 오프라인으로 동작합니다.
4. 로컬 모델 대신 API 모드(Solar)로도 쓸 수 있어서 AVX2를 지원하지 않는 오래된 PC에서도 동작합니다.
5. 화면에 아바타 캐릭터가 떠서 초안 작성 과정을 보여줍니다.

## 실행 환경

Windows 10 또는 11 x64, 클래식 데스크톱 Outlook(Office16 Win32)이 필요합니다. 로컬 모델을 쓰려면 AVX2를 지원하는 CPU, 여유 메모리 3GB 이상, 디스크 1.2GB 이상이 필요합니다. GPU가 있으면 Vulkan 1.x를 지원해야 하며 전용 또는 공유 메모리 1.6GB 이상을 권장합니다.

## 설치

Inno Setup으로 빌드한 설치 파일을 제공합니다. 설치 후 Outlook을 열면 메신저 창에 아바타가 나타납니다.
